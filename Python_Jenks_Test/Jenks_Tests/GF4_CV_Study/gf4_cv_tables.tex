%============= Table 5: FP4 codebook reconstruction error (interpretable) =============
% From GF4_CV_Study/codebook_error.py. Both codebooks use the SAME per-block RMS clip
% (clip_ratio 2.5, block 16); only the 8 levels differ. Relative RMS error is the
% quantization noise magnitude as a fraction of the signal magnitude
% (rel-RMS = ||x-Q(x)||/||x|| = 10^(-SNR_dB/20)) -- a direct, log-free reading of SNR.
\begin{table}[t]
  \centering
  \small
  \caption{FP4 codebook reconstruction error, reported as the quantization noise
    relative to the signal being quantized. \emph{Rel.\ RMS} $=\lVert x-Q(x)\rVert/
    \lVert x\rVert$ is the error magnitude as a percentage of the signal magnitude
    (equivalently $10^{-\mathrm{SNR_{dB}}/20}$); lower is better. GF4 (Gaussian
    equal-mass quantiles) and NVFP4 (uniform E2M1 levels) share an identical per-block
    RMS clip and block-16 scale, so the gap is purely the codebook. The Gaussian
    codebook helps most on well-behaved (near-Gaussian) signals and its advantage
    nearly vanishes once heavy-tailed outliers dominate the error -- consistent with
    the clip, not the codebook, being the primary driver at W4A4.}
  \label{tab:gf4-codebook-error}
